📘 BookVerse API
A Simple Book Management REST API built with FastAPI

🧠 Overview

BookVerse API is a lightweight and educational FastAPI project that allows users to manage a collection of books using standard RESTful API operations.
It demonstrates how to build, validate, and handle data in Python using FastAPI, Pydantic, and Starlette, making it an excellent example for beginners and intermediate developers learning modern Python API development.

✨ Key Features

✅ Fetch all available books
🔍 Retrieve a single book by its ID
⭐ Filter books by rating
📅 Retrieve books by published year
➕ Create (Add) new books
✏️ Update existing books
❌ Delete books from the collection
